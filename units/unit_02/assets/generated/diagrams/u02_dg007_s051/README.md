**Clasificación obligatoria:** ecuación anotada.

## Propósito

La energía elástica crece con `x²` y no conserva el signo de `x`.

## Archivos

- `source.json`: geometría, IDs, textos y conectores editables.
- `script.py`: regeneración reproducible.
- `u02_fig_051_007.svg`: fuente vectorial editable/importable.
- `u02_fig_051_007.png`: render individual de 2400 × 1100 px.
