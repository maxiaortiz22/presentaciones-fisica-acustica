# U04-CH-001 — Presión total y presión acústica

- Clasificación: gráfico cuantitativo.
- Skill: `chart-generation`.
- Variantes: u04_fig_001_presion_total_acustica, u04_fig_001b_presion_acustica_simple.
- Caption sugerido: La presión acústica es una pequeña variación respecto de la presión estática.
- Texto alternativo: Dos paneles temporales muestran una presión total siempre positiva y la variación acústica centrada en cero.
- Fuente de datos/modelo: Modelo sinusoidal ilustrativo basado en TEX 4.5.1; p0=101325 Pa, amplitud 0,20 Pa, 500 Hz.
- Escala: indicada en los ejes de cada variante; toda escala logarítmica se rotula explícitamente.
- Nota: las señales sintéticas y modelos ideales se declaran como tales; no representan mediciones.
