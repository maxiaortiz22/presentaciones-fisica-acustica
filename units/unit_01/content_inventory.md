# Unidad 1 — Inventario de contenido

## Criterio de clasificación

- **Imprescindible:** exigido por el programa o necesario para alcanzar los objetivos.
- **Importante:** ampliación del libro que reduce errores y prepara unidades futuras.
- **Complementario:** valioso si el tiempo y el ritmo lo permiten.
- **Respaldo:** solución, detalle técnico o referencia para consulta.
- **Fuera de alcance en esta unidad:** no debe desarrollarse aquí, aunque pueda mencionarse como puente.

## Magnitudes y notación

La notación siguiente es provisional hasta resolver las colisiones registradas en `open_decisions.md`.

| Magnitud | Símbolo del capítulo | Unidad | Relación introductoria | Observación |
|---|---:|---:|---|---|
| distancia | `d` | m | `d = c t` | La guía transversal propone `x` o `r` según contexto. |
| tiempo | `t` | s |  | Variable temporal. |
| intervalo de tiempo | `Δt` | s |  | No confundir con período `T`. |
| rapidez media | `v_med` | m·s⁻¹ | `v_med = d/Δt` | El capítulo usa rapidez para una razón escalar. |
| velocidad de propagación | `c` | m·s⁻¹ | `c = d/t` | No es velocidad de partícula. |
| aceleración media | `a_med` | m·s⁻² | `a_med = Δv/Δt` | Se formaliza en U2. |
| masa | `m` | kg |  | Magnitud fundamental. |
| peso | `F_g` | N | `F_g = m g` | Evitar `P` si puede confundirse con potencia. |
| fuerza | `F` | N | `F = m a` | Forma introductoria para masa constante y fuerza neta. |
| fuerza perpendicular | `F_⊥` | N |  | En presión media. |
| área | `A` en el capítulo | m² |  | La guía transversal prefiere `S`. |
| volumen | `V` | m³ |  | Volumen geométrico. |
| presión media | `p` | Pa | `p = F_⊥/A` | No es todavía presión acústica. |
| densidad de masa | `ρ` | kg·m⁻³ | `ρ = m/V` | Densidad de equilibrio futura: `ρ₀`. |
| frecuencia | `f` | Hz | `f = N/Δt` | `N` es un conteo adimensional. |
| nivel genérico de tipo potencia | `L_Q` | dB | `L_Q = 10 log₁₀(Q/Q₀)` | Anticipo; `Q/Q₀` debe ser adimensional. |

## Necesidades de nuevos recursos

### Gráficos o diagramas propios

- mapa visual del curso mostrando por qué U1 prepara U2–U4;
- magnitud–valor–unidad con objetos reales;
- rapidez, velocidad y propagación en una comparación única;
- red de magnitudes `d–t–c`, `m–a–F`, `F–S–p`, `m–V–ρ`;
- ejemplo de coherencia e incoherencia dimensional;
- función como tabla, flechas, ecuación y gráfico coordinados;
- inversa vs. recíproco;
- triángulo 3–4–5;
- grados/radianes/círculo unitario;
- exponencial y logaritmo reflejados respecto de `y=x`;
- escala lineal/logarítmica con razones;
- matriz “medición física / nivel referido / respuesta perceptual / conclusión clínica”.

### Imágenes técnicas

- fotografía o ilustración simple de una persona vocalizando frente a un micrófono;
- instrumento de medición o cadena parlante–micrófono;
- imagen del resorte o secuencia fotográfica de la demostración.

No se requiere imagen decorativa de ondas. Los visuales deben explicar una relación.

### Animaciones

- pulso en un resorte con una espira marcada;
- partículas que oscilan localmente mientras la perturbación avanza;
- construcción progresiva de una unidad derivada;
- ida y vuelta de función/inversa;
- barrido angular en círculo unitario;
- superposición conceptual de exponencial, identidad e inversa logarítmica;
- transformación de factores de diez en incrementos iguales de dB.

Toda animación debe conservar una alternativa estática comprensible.

### Demostraciones

- resorte largo, cinta liviana y espacio seguro;
- medición de distancia y tiempo para calcular rapidez;
- calculadora para potencias y logaritmos;
- comparación de un registro digital calibrado/no calibrado, si se dispone de material real.
