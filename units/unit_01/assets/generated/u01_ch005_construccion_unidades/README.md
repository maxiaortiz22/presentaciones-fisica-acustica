# U01-CH005 — Construcción de unidades derivadas

## Uso

- Slides: U01-021
- Pregunta: ¿Qué operaciones producen m/s, N y Pa?
- Escala: Diagrama algebraico; no aplica escala.

## Archivos

- `script.py`: regenera este recurso.
- `u01_fig_005_construccion_unidades.svg`: salida vectorial editable/importable.
- `u01_fig_005_construccion_unidades.png`: salida raster de alta resolución.
- `data.csv`: datos, relaciones o nodos usados.
- `caption.txt`: caption sugerido.
- `alt_text.txt`: texto alternativo.
- `source.txt`: fuente del modelo o de los datos.

## Reproducción

Ejecutar desde esta carpeta:

```powershell
python script.py
```

## Fuente

BIPM, SI Brochure, 9.ª edición; elaboración propia.

## Validación específica

1 N = 1 kg·m/s² y 1 Pa = 1 N/m².
