# U01-CH022 — Razón de potencia y decibel

## Uso

- Slides: U01-070–U01-071
- Pregunta: ¿Cómo se transforma una razón de potencia en dB?
- Escala: Eje x logarítmico de 1 a 1000; eje y lineal de 0 a 30 dB.

- `u01_fig_022_razon_db.svg`: salida vectorial editable/importable.
- `u01_fig_022_razon_db.png`: salida raster de alta resolución.
- `data.csv`: datos, relaciones o nodos usados.
- `caption.txt`: caption sugerido.
- `alt_text.txt`: texto alternativo.
- `source.txt`: fuente del modelo o de los datos.

## Reproducción

Ejecutar desde esta carpeta:

```powershell
python script.py
```
