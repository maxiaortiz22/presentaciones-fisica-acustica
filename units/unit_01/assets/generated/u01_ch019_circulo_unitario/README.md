# U01-CH019 — Círculo unitario y radianes

## Uso

- Slides: U01-053; U01-058–U01-061; U01-090
- Pregunta: ¿Cómo conectan grados, radianes y proyecciones?
- Escala: Ejes lineales adimensionales de -1,2 a 1,2.

## Archivos

- `script.py`: regenera este recurso.
- `u01_fig_019_circulo_unitario.svg`: salida vectorial editable/importable.
- `u01_fig_019_circulo_unitario.png`: salida raster de alta resolución.
- `data.csv`: datos, relaciones o nodos usados.
- `caption.txt`: caption sugerido.
- `alt_text.txt`: texto alternativo.
- `source.txt`: fuente del modelo o de los datos.

## Reproducción

Ejecutar desde esta carpeta:

```powershell
python script.py
```

## Fuente

Libro del curso, Unidad 1, figura círculo trigonométrico; elaboración propia.

## Validación específica

Radio unitario, 360°=2π rad y cos²θ+sin²θ=1.
