# U07-CH-001

- **Clasificación obligatoria:** gráfico cuantitativo.
- **Pregunta:** ¿Por qué un criterio selecciona un punto de una transición gradual?
- **Estado:** aprobado como asset v01 tras render individual y simulación a tamaño final 16:9.
- **Escala:** x e y lineales.
- **Fuente de datos/modelo:** Función logística sintética definida en chart_plan.md; no son datos humanos.
- **Reproducción:** ejecutar `u07_plot_001_curva_psicometrica.py` en esta carpeta o `units/unit_07/scripts/u07_generate_charts.py U07-CH-001`.

## Caption sugerido

La detección aumenta gradualmente con el nivel; el criterio del 50 % define L₅₀ para este procedimiento, no un umbral universal.

## Texto alternativo

Curva logística de detección desde casi cero hasta casi cien por ciento. Una línea horizontal en cincuenta por ciento corta la curva en L cincuenta.

## Límites

Figura conceptual y no normativa.
