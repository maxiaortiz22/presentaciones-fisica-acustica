# U07-CH-009

- **Clasificación obligatoria:** gráfico cuantitativo.
- **Pregunta:** ¿Qué mide T₆₀?
- **Estado:** aprobado como asset v01 tras render individual y simulación a tamaño final 16:9.
- **Escala:** ambos ejes lineales.
- **Fuente de datos/modelo:** Decaimiento log-lineal sintético con T₆₀=1,2 s; sin fórmula de Sabine ni medición de recinto.
- **Reproducción:** ejecutar `u07_plot_009_decaimiento_t60.py` en esta carpeta o `units/unit_07/scripts/u07_generate_charts.py U07-CH-009`.

## Caption sugerido

T₆₀ es el intervalo de un decaimiento ideal de 60 dB; no significa tiempo hasta silencio.

## Texto alternativo

Recta descendente desde cero decibeles relativos en cero segundos hasta menos sesenta decibeles en uno coma dos segundos, con piso de ruido conceptual.

## Límites

Figura conceptual y no normativa.
