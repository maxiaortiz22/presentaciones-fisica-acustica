# U05-CH-018

- **Clasificación:** gráfico cuantitativo
- **Pregunta:** ¿Qué nivel constante tiene la misma energía media que un nivel variable?
- **Modelo/datos:** Libro del curso, ejemplo de nivel equivalente, sección 5.11.
- **Escala y tamaño:** canvas 16:9; PNG 2560×1440; SVG con texto editable.
- **Reproducción:** `python u05_plot_018_nivel_equivalente.py`

## Caption sugerido

Treinta segundos a 70 dB y treinta segundos a 80 dB equivalen energéticamente a un nivel constante de 77,4 dB durante 60 segundos.

## Texto alternativo

Gráfico temporal con dos tramos de nivel, primero setenta y luego ochenta decibeles. Una línea discontinua horizontal marca el nivel equivalente de 77,4 decibeles.

## Fuente de datos

Libro del curso, ejemplo de nivel equivalente, sección 5.11.
