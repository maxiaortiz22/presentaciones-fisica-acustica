# U05-CH-002

- **Clasificación:** gráfico cuantitativo
- **Pregunta:** ¿Qué información cambia entre tiempo, magnitud y fase?
- **Modelo/datos:** Libro del curso, Unidad 5, figura 5.1 y ecuaciones asociadas; modelo matemático determinista.
- **Escala y tamaño:** canvas 16:9; PNG 2560×1440; SVG con texto editable.
- **Reproducción:** `python u05_plot_002_tiempo_magnitud_fase.py`

## Caption sugerido

La misma presión sintética se representa en el tiempo y mediante magnitud de pico y fase de su DFT unilateral.

## Texto alternativo

Tres paneles coordinados muestran una señal temporal y líneas en 100 y 200 hertz. La magnitud de pico es 0,20 y 0,05 pascales; las fases son menos pi medios y cero radianes según la convención de coseno de la DFT.

## Fuente de datos

Libro del curso, Unidad 5, figura 5.1 y ecuaciones asociadas; modelo matemático determinista.
