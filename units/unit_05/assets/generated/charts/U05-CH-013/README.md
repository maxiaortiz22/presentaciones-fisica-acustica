# U05-CH-013

- **Clasificación:** gráfico cuantitativo
- **Pregunta:** ¿Qué significa ubicar infra, audible y ultra si las fronteras son aproximadas?
- **Modelo/datos:** Programa oficial y libro del curso, sección 5.7; fronteras convencionales, no límites universales.
- **Escala y tamaño:** canvas 16:9; PNG 2560×1440; SVG con texto editable.
- **Reproducción:** `python u05_plot_013_regiones_frecuencia.py`

## Caption sugerido

Regiones frecuenciales convencionales sobre eje logarítmico; las transiciones próximas a 20 Hz y 20 kHz son aproximadas.

## Texto alternativo

Eje logarítmico de uno a un millón de hertz con regiones de infrasonido, rango audible y ultrasonido. Dos bandas rayadas señalan transiciones aproximadas alrededor de veinte hertz y veinte kilohertz.

## Fuente de datos

Programa oficial y libro del curso, sección 5.7; fronteras convencionales, no límites universales.
