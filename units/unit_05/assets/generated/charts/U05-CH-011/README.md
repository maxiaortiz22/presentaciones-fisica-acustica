# U05-CH-011

- **Clasificación:** gráfico cuantitativo
- **Pregunta:** ¿Cómo distinguimos fundamental, armónicos, parciales y fundamental ausente?
- **Modelo/datos:** Libro del curso, Unidad 5, figura 5.5; datos teóricos declarados.
- **Escala y tamaño:** canvas 16:9; PNG 2560×1440; SVG con texto editable.

## Caption sugerido

Tres espectros teóricos separan serie armónica, parciales inarmónicos y fundamental ausente con una misma escala.

## Texto alternativo

Tres paneles de líneas espectrales. El primero muestra armónicos de cien hertz con el segundo armónico como máximo; el segundo contiene parciales no múltiplos; el tercero omite la línea de cien hertz pero conserva separación de cien hertz.
