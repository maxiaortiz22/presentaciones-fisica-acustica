# U05-CH-001

- **Clasificación:** gráfico cuantitativo
- **Pregunta:** ¿Dos señales con el mismo RMS contienen la misma información?
- **Modelo/datos:** Modelo matemático determinista; continuidad con Unidad 4 y brief de Unidad 5.
- **Escala y tamaño:** canvas 16:9; PNG 2560×1440; SVG con texto editable.
- **Reproducción:** `python u05_plot_001_igual_rms.py`

## Caption sugerido

Dos señales sintéticas normalizadas al mismo valor RMS conservan formas temporales distintas.

## Texto alternativo

Dos paneles temporales con ejes comunes comparan una senoide y una señal armónica no sinusoidal. Ambas indican RMS igual a 0,707, aunque sus formas y picos son diferentes.

## Fuente de datos

Modelo matemático determinista; continuidad con Unidad 4 y brief de Unidad 5.
