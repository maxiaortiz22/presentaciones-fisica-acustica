# U05-CH-006

- **Clasificación:** gráfico cuantitativo
- **Pregunta:** ¿Cuándo dos frecuencias continuas producen las mismas muestras?
- **Modelo/datos:** Modelo matemático de muestreo uniforme; elaboración propia basada en el capítulo 5.
- **Escala y tamaño:** canvas 16:9; PNG 2560×1440; SVG con texto editable.
- **Reproducción:** `python u05_plot_006_muestreo_aliasing.py`

## Caption sugerido

Con muestreo a 1000 Hz, las senoides de 150 Hz y 850 Hz con fase indicada coinciden exactamente en los instantes muestreados.

## Texto alternativo

Dos paneles muestran ondas continuas diferentes y los mismos puntos de muestreo. Se indica frecuencia de muestreo de mil hertz y separación temporal de una milésima de segundo.

## Fuente de datos

Modelo matemático de muestreo uniforme; elaboración propia basada en el capítulo 5.
