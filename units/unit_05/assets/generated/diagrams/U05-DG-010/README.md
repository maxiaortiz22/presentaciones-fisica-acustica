## Caption sugerido

Taxonomía de cuatro filtros vinculada con una cadena entrada–filtro–salida.

## Texto alternativo

Una cadena superior conecta entrada, filtro y salida. Desde el filtro parten cuatro ramas sin cruces hacia pasa bajos, pasa altos, pasa banda y elimina banda.
