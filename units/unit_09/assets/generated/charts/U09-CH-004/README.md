# U09-CH-004 — llegadas_reverberacion

- **Clasificación:** gráfico cuantitativo.
- **Pregunta:** ¿Qué diferencia temporal existe entre una reflexión aislada y una cola reverberante?
- **Estado:** aprobado tras controles numéricos, render individual y simulación 16:9.
- **Tamaño físico final:** 7.0 × 4.1 in.
- **Escala:** consultar ejes y `parameters.json`.
- **Reproducción:** `python units/unit_09/scripts/u09_plot_004_llegadas_reverberacion.py`.

## Caption sugerido

Señales sintéticas coordinadas distinguen llegada directa, reflexión aislada y una densidad creciente de llegadas con cola.

## Texto alternativo

Tres paneles con igual eje temporal. El primero contiene una llegada directa; el segundo agrega una reflexión aislada; el tercero muestra muchas llegadas decrecientes que forman una cola.

## Fuente de datos

Señales temporales sintéticas y conceptuales; parámetros en parameters.json. No se fija un umbral perceptual universal.
