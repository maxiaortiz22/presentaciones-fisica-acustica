# U09-CH-005 — lambda_frecuencia

- **Clasificación:** gráfico cuantitativo.
- **Pregunta:** ¿Qué escalas espaciales corresponden a distintas frecuencias?
- **Estado:** aprobado tras controles numéricos, render individual y simulación 16:9.
- **Tamaño físico final:** 7.2 × 4.2 in.
- **Escala:** consultar ejes y `parameters.json`.
- **Reproducción:** `python units/unit_09/scripts/u09_plot_005_lambda_frecuencia.py`.

## Caption sugerido

Relación inversa entre frecuencia y longitud de onda para c = 343 m·s⁻¹, con ejemplos en 125, 500 y 4000 Hz.

## Texto alternativo

Curva recta descendente en ejes logarítmicos. Se marcan longitudes de onda de 2,74 metros a 125 hertz, 0,686 metros a 500 hertz y 0,0858 metros a 4000 hertz.

## Fuente de datos

Relación λ = c/f con c = 343 m·s⁻¹, referencia didáctica próxima a 20 °C. Datos calculados.
