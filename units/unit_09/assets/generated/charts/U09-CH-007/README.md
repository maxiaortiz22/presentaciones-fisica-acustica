# U09-CH-007 — tau_R

- **Clasificación:** gráfico cuantitativo.
- **Pregunta:** ¿Cómo se transforma la fracción transmitida τE en R?
- **Estado:** aprobado tras controles numéricos, render individual y simulación 16:9.
- **Tamaño físico final:** 7.0 × 4.1 in.
- **Escala:** consultar ejes y `parameters.json`.
- **Reproducción:** `python units/unit_09/scripts/u09_plot_007_tau_R.py`.

## Caption sugerido

Relación logarítmica ideal entre fracción energética transmitida e índice de reducción; cada década menos de transmisión suma 10 dB.

## Texto alternativo

Curva recta ascendente mientras el eje horizontal decrece desde uno hasta una millonésima. Se marcan uno, cero coma uno y cero coma cero uno por ciento.

## Fuente de datos

Modelo del capítulo 9: R = 10 log10(1/τE). Datos calculados; elemento ideal, no aislamiento in situ.
