## Revisión pedagógica y física

- Se distingue movimiento local de propagación mediante dirección, rótulo y color.
- Se evita representar al aire como una onda transversal.
- Los esquemas conceptuales que no están a escala lo declaran.
- `u` y `c` conservan referentes distintos.
- Las ecuaciones usan `k_s` para rigidez y `k_onda` para número de onda.
- La cancelación activa se presenta como efecto espacial limitado.
- La suma instantánea no se confunde con suma automática de amplitudes.
- La cadena de calibración no se presenta como resultado clínico.

- `script.py`;
- SVG editable;
- PNG de alta resolución;
