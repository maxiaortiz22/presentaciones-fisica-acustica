## Instalación sugerida

1. Copiar `AGENTS.md` en la raíz del repositorio.
2. Copiar la carpeta `skills/` dentro del repositorio.
3. Abrir el repositorio completo en Codex.
4. Ejecutar primero `course-architecture` y `style-system`.
5. Para cada unidad usar: `unit-storyboard` → `asset-curation` / `chart-generation` → `slide-writing` → `deck-review` → `consistency-guard`.
